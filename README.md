# Movie Review Website

This is a responsive movie review website I created as a college project. It uses a movie API to fetch and display movie information, including details, ratings and reviews.

The website also uses Local Storage to save certain user information and preferences. I designed it to work well on different screen sizes, including desktop, tablet and mobile.

## Features

* Browse and search for movies
* View movie information
* View ratings and reviews
* Uses a movie API
* Uses Local Storage
* Responsive design for different screen sizes

## Technologies Used

* HTML
* CSS
* JavaScript
* Movie API
* Local Storage
